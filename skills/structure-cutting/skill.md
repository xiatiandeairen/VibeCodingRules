# 结构裁剪（Structure Cutting）

## 作用

在设计阶段，**主动减少结构复杂度**。  
合并模块、拒绝扩展性、强行降维。

## 可训练行为

- 把设计压到 ≤ 4 个步骤
- 每个步骤只一句话

## 步骤

1. **承接 Intent**：根据 intent-compression 的输出确定设计范围
2. **合并**：能合并的模块就合并，不保留「未来可能」的扩展点
3. **降维**：把设计压到 ≤ 4 个步骤，每步一句话
4. **自检**：一句话能复述整个流程 → 通过；结构解释超过 30 秒 → 继续裁剪

## 输出规范

**设计格式：**
```markdown
## 设计（≤4 步）

1. [步骤 1 - 一句话]
2. [步骤 2 - 一句话]
3. [步骤 3 - 一句话]
4. [步骤 4 - 一句话]（可选）

## 复述测试
[用一句话复述整个流程]
```

## 自评标准

| 状态 | 含义 |
|------|------|
| ❌ 结构解释超过 30 秒 | 继续裁剪，删东西 |
| ✅ 一句话能复述整个流程 | 可进入执行推进 |

## 使用说明

- **调用时机**：intent 明确后，在执行推进之前
- **上游**：依赖 `intent-compression` 的输出
- **下游**：输出传给 `execution-momentum` 作为实现依据
- **原则**：主动删，不解释「为什么需要」
