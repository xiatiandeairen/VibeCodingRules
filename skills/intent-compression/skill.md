# 意图压缩（Intent Compression）

## 作用

把一个模糊想法，快速压缩成**可执行的最小目标**。  
删掉「背景」和「动机」，只留下「要干嘛 / 做到什么程度 / 不做什么」。

## 可训练行为

- 用 ≤ 5 行写清一个任务
- 能当场回答「现在不做什么」

## 步骤

1. **剥离**：去掉背景、动机、理由，只保留行动目标
2. **压缩**：把目标写成 ≤ 5 行，每行一个可执行点
3. **划界**：明确写出「这次不做什么」（至少 1 条）
4. **自检**：写不出来 → 想法还不成熟，先澄清；一遍写完 → 可进入结构裁剪

## 输出规范

**Intent 格式：**
```markdown
## 要干嘛
- [可执行点 1]
- [可执行点 2]
- ...

## 做到什么程度
- [验收标准，可检查]

## 不做什么
- [明确排除项 1]
- [明确排除项 2]
```

## 自评标准

| 状态 | 含义 |
|------|------|
| ❌ 写不出来 | 想法还不成熟，需要先澄清 |
| ✅ 一遍写完 | 可以进入设计（结构裁剪） |

## 使用说明

- **调用时机**：所有任务启动时，在结构裁剪之前
- **下游**：输出传给 `structure-cutting` 作为设计输入
- **注意**：不追求「完美表述」，追求「能执行」
