# 低成本反思（Lightweight Reflection）

## 作用

用最小代价，为下一次降低阻力。  
只记录摩擦点，不总结经验，不上升方法论。

## 可训练行为

- 每次只写 3 条
- ≤ 5 分钟完成
- 写完就关文档

## 步骤

1. **回顾**：快速过一遍本次任务的 5 个阶段（意图→设计→执行→验证→反思）
2. **抓摩擦**：只记「哪里卡了」「什么阻碍了推进」
3. **3 条封顶**：最多写 3 条，每条一句话
4. **收尾**：写完就关，不展开、不总结、不写方法论

## 输出规范

**摩擦点格式：**
```markdown
## 摩擦点（≤3 条）

1. [摩擦点 1 - 一句话]
2. [摩擦点 2 - 一句话]
3. [摩擦点 3 - 一句话]（可选）
```

## 自评标准

| 状态 | 含义 |
|------|------|
| ❌ 想「系统总结一下」 | 过度反思，停 |
| ✅ 写完就关文档 | 反哺下一次意图压缩 |

## 使用说明

- **调用时机**：目标对照验证通过后，或任务告一段落时
- **上游**：依赖完整任务流程的体验
- **下游**：反哺下一次 `intent-compression`（避免重复摩擦）
- **原则**：记摩擦，不记经验；记现象，不记规律
